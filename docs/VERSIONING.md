# Versionamento do Baixa Fácil

- Versão atual: `0.1.0-alpha.45`.
- `versionCode`: `45`.
- Próxima versão sequencial: `0.1.0-alpha.46`, `versionCode 46`.
- Toda mudança sincroniza Gradle, UI Sobre, User-Agent, GitHub Actions, README, CHANGELOG, RELEASE_NOTES, docs/VALIDATION e pré-teste do publicador.
- O APK é publicado como único asset `.apk` em GitHub Releases, sem ZIP em Artifacts.
- Os 4 Secrets de assinatura são confidenciais e não devem ser versionados.
